# auth.py — сбор куки Arena (arena.ai)

Скрипт собирает cookies для `arena_generator.py` по одному аккаунту:
логинишься в открытом окне → Enter → `cookies/account_1.json` → Enter → `cookies/account_2.json` → …

Файлы кладутся в `cookies/` рядом со скриптом; генератор сам находит все `*.json` в этой папке.

## Быстрый старт

```bat
python auth.py --check        :: диагностика: Python, Playwright, браузеры, папка куки
python auth.py --install      :: доустановить Chromium (тем же питоном!)
python auth.py                :: рабочий режим: вход -> Enter -> account_N.json
```

## «Failed to verify your browser, Code 21» — что это

Это **Vercel Security Checkpoint** — антибот-защита, на которой хостится arena.ai (бывший lmarena.ai).
Коды (11, 21, 705…) — её внутренние. Скрипт тут не виноват: защита не пускает автоматизированный браузер.

Порядок действий (от простого к надёжному):

1. **Подождать и нажать Enter ещё раз.** Чекап часто пропускает страницу сам через 10–30 секунд;
   скрипт уже ждёт его автоматически (`CHECKPOINT_SECONDS`) и печатает эти подсказки.
2. **Запустить с реальным Chrome** — встроенный Chromium палится чаще:
   ```bat
   python auth.py --channel chrome
   ```
   `--channel auto` (по умолчанию) сам пробует Chrome → Edge → встроенный Chromium.
3. **Выключить VPN, сменить сеть.** «Засвеченные» IP чекап не пропускает.
4. **Обойти полностью — перенести куки из обычного браузера** (самый надёжный способ):
   1. залогинься на arena.ai в своём Chrome;
   2. расширение **Cookie-Editor** → `Export` → `JSON` (для домена arena.ai);
   3. сохрани файл и выполни:
      ```bat
      python auth.py --import cookies.json
      ```
   Браузер вообще не запускается, Playwright не нужен.

## Параметры

| Параметр | Что делает |
|---|---|
| `--check` | диагностика без входа: окружение, доступные браузеры, папка куки |
| `--install` | доустановить Chromium без вопросов |
| `--import FILE` | перенести куки из экспорта Cookie-Editor/EditThisCookie (без браузера) |
| `--channel chrome\|msedge\|chromium\|auto` | какой браузер запускать (auto: Chrome → Edge → Chromium) |
| `--profile [DIR]` | постоянный профиль (по умолчанию `auth_profile/`), один аккаунт за запуск |
| `--dir DIR` | куда сохранять `account_N.json` |
| `--url URL` | стартовый адрес (по умолчанию `https://arena.ai/`) |
| `--all` | сохранять куки всех доменов, а не только arena.ai |
| `--no-verify` | не проверять вход после Enter |

## Что важно знать

* **Папку `cookies/` скрипт создаёт сам** — `storage_state()` этого не делает
  (отсюда бывает `FileNotFoundError: cookies/arena_cookies.json`).
* Существующие `account_N.json` **не перезаписываются**: нумерация продолжается с первого свободного номера.
* Каждый аккаунт — **чистый контекст**: предыдущая сессия Arena/Google не тянется.
* По умолчанию сохраняются **только куки `arena.ai`** (+ его localStorage): гугловые сессии в файл не попадают.
* После Enter скрипт проверяет вход (ищет `Log out` / меню аккаунта) и говорит, подтверждён он или нет.
* Файлы куки — это живые сессии: не коммить их, `cookies/` уже в `.gitignore`.

## Если браузер не запускается

```bat
python auth.py --check
```

Скрипт печатает точную причину и что сделать: нет бинарника Chromium (даёт команду установки **тем же
интерпретатором**), не хватает системных библиотек, нет X-сервера (для Linux/VPS — `xvfb-run`),
антивирус блокирует `chrome.exe` на Windows. Ошибки Playwright сжимаются в одну строку, трейсбека нет.
