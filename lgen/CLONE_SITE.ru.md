# Клон сайта — режим бота LGen

Пользовательская функция за токены. Нужна дизайнерам и фронтенд-разработчикам:
пользователь присылает ссылку на **свой** сайт (или сайт, на копирование дизайна которого у него есть разрешение),
бот анализирует компоновку, цвета, шрифты и тексты-ориентиры и строит **новый** лендинг через обычный генератор LGen
(тот же ключ и бэкенд, что и у режима «Лендинг»). Стоимость: `COST_LANDING` (2 500 000 токенов).

## Поток

1. Меню → «🧬 Клон сайта» → экран с предупреждением.
2. Пользователь присылает URL. Адрес проверяется сразу (отказ — токены не списываются).
3. Подтверждение: «Подтверждаю, у меня есть права». Без подтверждения ничего не загружается.
4. Проверка баланса и лимитов, загрузка HTML и CSS, повторная проверка страницы.
5. Списание токенов и генерация. При ошибке токены возвращаются (поведение `_run_generation`).
6. Результат — архив. Страница не публикуется и не хостится.

## Что проверяет код (`site_clone.py`)

| Проверка | Где |
|---|---|
| Только `http`/`https`, порты 80/443, без логина и пароля в URL, длина ≤ 2048 | `validate_url` |
| Запрет `localhost`, внутренних зон (`.local`, `.internal`…) и IP-литералов | `validate_url` |
| Запрет доменов, резолвящихся во внутреннюю сеть (SSRF); проверка всех A/AAAA-записей | `validate_url` |
| Редиректы и CSS-файлы проверяются заново; до 3 редиректов; без cookies | `_get_following_redirects` |
| Отказ для доменов и путей входа, оплаты, банков, почты (`/login`, `/checkout`, `bank…`, `pay…`, `mail`…) | `validate_url` |
| Отказ, если в HTML есть `type=password`, `autocomplete=cc-number`/`one-time-code`, поля карт и кодов | `detect_sensitive` |
| Отказ для страниц-оболочек SPA (формы не видны на сервере) | `looks_like_js_shell` |
| Изображения, видео и шрифты сторонних сайтов не скачиваются; в промпт попадает только описание | `build_snapshot`, `build_clone_prompt` |
| Cooldown (`CLONE_COOLDOWN_SECONDS`, по умолчанию 120 с) и суточная квота (`CLONE_DAILY_LIMIT`, по умолчанию 5) | `CloneRateLimiter` |

## Ограничения (важно)

- Эвристики **не дают гарантии**. Страница, которая прячет форму входа за JavaScript, отсекается только
  если на сервере нет текста; сайт с редкими правилами по доменам может пройти фильтр.
- Лимиты хранятся в памяти процесса: после перезапуска бота сбрасываются.
- Логирование: в лог пишутся `user_id` и хост (не полный URL и не содержимое страницы), для ручного просмотра администратором.
  Журнал запросов для админ-панели не сделан.
- Использование результата и соблюдение прав третьих лиц — ответственность пользователя.
  Текст «LGen не несёт ответственности» в боте не заменяет юридическую проверку оператора сервиса.

## Тесты

```
cd lgen
pytest tests/test_site_clone.py
```

Тесты не ходят в сеть: DNS и HTTP подменяются. Обработчики бота проверены вручную на фейковых объектах
aiogram (отказ по адресу, подтверждение, отказ фетча без списания, передача в генерацию, cooldown).
Реальный запуск с arena.ai и сайтом из интернета в песочнице не выполнялся.
